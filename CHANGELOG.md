# Changelog

## 1.0.0
- Initial release: 77 offline security rules (secrets, injection, XSS, deserialisation, crypto/TLS, config).
- Live diagnostics with CWE links, quick fixes, per-line / per-file / per-rule ignore.
- Dependency advisories for `package.json`, `package-lock.json`, `requirements.txt` (starter dataset).
- Sidebar tree view, security dashboard, SARIF and Markdown export.
- Zero-dependency CLI for CI pipelines.
