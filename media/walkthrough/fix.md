# Fix with one click

Hover any underlined code to read what is wrong and how to fix it.
Press **Ctrl+.** (**Cmd+.** on macOS) to open the quick-fix menu:

- ✅ Apply the suggested fix (e.g. `md5` → `sha256`)
- 🙈 Ignore the finding with a `shieldlocal-ignore` comment
- 🔕 Disable the rule for this workspace
